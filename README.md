## Шифр Цезаря

**Шифр подстановки**, в котором каждая буква <br>
сдвигается на фиксированное количество позиций.


****Пример:****

```console
Введите строку
Hello world

Введите сдвиг
3

----- Шифр Цезаря -----
Зашифрованная строка с помощью шифра Цезаря: Khoor zruog
Расшифровано: Hello world
Текст успешно восстановлен
```

Особенности:
- Сохраняет регистер букв
- Корректно зацикливает алфавит (Z -> A)
- Поддерживает отрицательный сдвиг (Hello world -> Ebiil tloia) (сдвиг -3)

<br>

## Шифр Виженера

**Полиалфавитный Шифр**, в котором величина сдвига <br>
определяется символами ключевого слова.

****Пример:****

```console
Введите строку
Hello world

Введите ключ
KEY

----- Шифр Винжера -----
Зашифрованная строка с помощью шифра Вижера: Rijvs uyvjn
Расшифровано: Hello world
Текст успешно восстановлен
```

****Особенности:****
- Ключ состоит только из букв латинского алфавита
- Неалфавитные ключи не изменяют исходный текст
